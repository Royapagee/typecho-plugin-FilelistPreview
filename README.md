# FilelistPreview —— Typecho 后台附件列表图片预览

在后台撰写文章、独立页面以及编辑附件时，为上传面板（`#upload-panel`）里的图片附件生成缩略图，显示在每个文件名上方，方便上传后快速确认图片内容。

## 功能特性

- **文件名上方缩略图**：图片附件在文件名前插入固定高度的预览图，非图片文件保持原样；
- **自动覆盖已有与新增附件**：服务端已经渲染的附件和上传完成后动态插入的附件都会自动补上预览；
- **按需加载**：使用浏览器原生 `loading="lazy"`，附件面板未显示或缩略图在视口外时不会请求原图；
- **点击查看大图**：点击缩略图在当前页放大查看，支持 `Esc`、点击遮罩或关闭按钮退出；也可以在插件设置中改为在新标签页打开原图；
- **不修改数据库和模板**：纯前端实现，通过后台钩子注入 CSS / JS，禁用插件后界面恢复原样。

## 兼容性

| 项目 | 要求 |
| ------ | ------ |
| 系统 | Typecho 1.3.0（`TypechoPlugin` 命名空间） |
| 语言 | PHP 7.4+ |
| 浏览器 | 现代浏览器；不支持原生懒加载时浏览器会直接加载全部缩略图 |

## 安装

1. 将插件目录放入 `usr/plugins/FilelistPreview`；
2. 登录后台 → **控制台 → 插件**，找到 **FilelistPreview**，点击 **启用**；
3. 可选：在插件 **设置** 中调整预览高度和点击行为。

无需额外配置即可使用；未保存过设置时预览高度为 120px，点击缩略图在当前页放大。

## 设置项

| 设置 | 说明 |
| ------ | ------ |
| 预览高度 | 缩略图高度，单位为像素，可填 60 ~ 400，默认 120；宽度随上传面板自动铺满 |
| 查看大图 | `点击后在当前页放大查看`（默认）或 `点击后在新标签页打开原图` |

缩略图始终显示在文件名上方，设置只影响点击后的行为。

## 工作方式

`Plugin.php` 通过后台页脚钩子注入资源：

```php
\Typecho\Plugin::factory('admin/footer.php')->end = __CLASS__ . '::render';
```

`render()` 只在 `write-post.php`、`write-page.php`、`media.php` 三个带上传面板的页面输出资源，并按文件修改时间追加 `?v=` 版本号。

`static/filelistpreview.js` 在 DOM 就绪后扫描 `#file-list`，读取每个条目的 `data-image` 与 `data-url`：

- 已有的附件由服务端输出这两个属性；
- 新上传的附件由 `file-upload-js.php` 通过 jQuery `.data()` 写入，所以脚本统一使用 `.data()` 读取；
- 使用 `MutationObserver` 监听列表变化，上传完成后自动补上缩略图，删除附件时缩略图随条目一起移除。

图片加载失败时缩略图会被静默移除，不影响文件列表的其他操作。

## 已知说明

- 预览使用附件原图地址，由浏览器缩放到缩略图尺寸；插件不生成服务端缩略图，也不写入任何文件；
- 仅对 `isImage` 为真的附件（MIME 为图片）显示预览；
- 附件在后台被删除或替换后，预览会随文件列表同步更新。
